# Markup mockup

File `.dc.html` ini adalah sumber mockup dari kanvas desain. File ini tidak bisa dibuka langsung di browser karena butuh runtime editor desain. Gunakan hanya sebagai referensi ukuran (px), urutan elemen, teks, dan data dummy. Untuk tampilannya, lihat `../screens/*.png`.

- `Sidebar`, `Topbar`, dan `Drawer` adalah potongan yang dipakai ulang oleh halaman lain.
- `<x-import component-from-global-scope="Ariadne.X" ...>` berarti komponen design system `X` dengan props tersebut (lihat `../design-system/components/index.d.ts`).
