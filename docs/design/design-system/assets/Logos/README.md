# Logos

- `ariadne-mark.svg` — the mark for light grounds: walls in `ink` (#1a2130), thread and knot in `thread` (#c9342a). Two inks, fixed; use it where the `Logo` component can't run (email, documents, favicon).
- `ariadne-mark-dark.svg` — the same mark for dark grounds: walls #e6e9ef, thread #ff806b.
- There is no wordmark file: set "Ariadne" in IBM Plex Sans 600 beside the mark, as the `Logo` component does. Keep clear space of half the mark's width on every side; minimum size 16px.
