# Icons

The status and priority glyphs as standalone SVGs for places React can't reach (email notifications, exported documents). Each is drawn in its light-theme colour; in the product, use `Ariadne.Icon` (`name: "status-…"` / `"priority-…"`), which draws in `currentColor` and follows the theme. The full UI icon set (navigation, actions) lives only in `Icon`. Icon geometry follows Lucide's 24px grid (ISC licence); the wrench, repeat and bell paths are Lucide's.
