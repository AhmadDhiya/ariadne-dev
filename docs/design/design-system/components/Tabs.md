# Tabs

Underlined view switcher for a project: Tabel | Gantt | Milestone | Anggota.

- Props: `items` (strings or `{label}`), `active` (label).
- The selected tab is `primary` text with a 2px `primary` underline; the rest are `ink-muted`.
- For zoom (Hari / Minggu / Bulan) use a segmented group of `secondary` small Buttons, not Tabs — tabs change the view, zoom changes the scale.
