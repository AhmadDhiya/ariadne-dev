# Icon

Line icons on a 24px grid with a 1.75 stroke in `currentColor`; set the colour with CSS `color`.

- Props: `name`, `size` (default 16), `title` (gives the icon an accessible name; omit when a text label sits beside it).
- Sizes: 16 in rows, buttons and menus; 18 in the top bar; 14 inside pills and chips; 12 inside Gantt bars.
- Names: `dashboard timeline folder users settings search bell plus x check chevron-down chevron-right lock info message update at move calendar eye more milestone mail`, the eight `status-*` glyphs and the four `priority-*` glyphs.
- An icon never carries meaning alone: pair it with a word, or give it a `title`.
