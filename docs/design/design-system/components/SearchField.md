# SearchField

A search input with a leading magnifier and an optional keyboard hint.

- Props: `placeholder` (default "Cari task, proyek, orang…"), `value`, `shortcut` (e.g. "/"), `width`.
- Global search sits in the top bar at 360px with `shortcut: "/"`. The project filter bar uses a 220px field, "Cari di proyek ini".
- Border is `line-strong` (3:1); focus shows the `focus-ring`.
